# 🏥 HealthInsight Pro: Akıllı Sağlık Asistanı

Samsun Üniversitesi Yazılım Mühendisliği - Mobil Challenge Projesi kapsamında geliştirilen, Pinterest #836021 nolu panodan ilham alan kapsamlı bir sağlık takip uygulamasıdır.

## 🚀 Projenin Özeti
HealthInsight Pro, kullanıcıların KOAH eğitimlerinden kan şekeri analizine, günlük mod takibinden acil yardım hatlarına kadar tüm sağlık süreçlerini tek bir merkezden yönetmesini sağlar.

## ✨ Öne Çıkan Özellikler & Çözümler
- **Akıllı Analiz:** Kan şekeri verilerini sadece kaydetmez, (Normal/Düşük/Yüksek) olarak analiz eder.
- **Dinamik Eğitim:** KOAH egzersizleri arasında anlık arama ve filtreleme.
- **Duygu Günlüğü:** Kullanıcının psikolojik durumunu tarih bazlı notlarla takip eden interaktif sistem.
- **Hedef Odaklılık:** Adım ve su tüketimi için görsel Progress Bar (İlerleme Çubuğu) takibi.

## 🧪 Teknik Şartname Karşılama
- **Navigasyon:** 8+ farklı ekran içeren kompleks Stack Navigation yapısı.
- **Hata Yönetimi:** Veri bulunamadığında "Empty State" ve yükleme anında "Loading" gösterimi.
- **Modern UI:** Pinterest tasarım diliyle uyumlu, gölgeli ve yuvarlatılmış kart tasarımları.
- **Dış Entegrasyon:** WhatsApp ve Telefon hatları için Linking API kullanımı.

## 🛠 Kurulum
1. `npm install`
2. `npx expo start`
